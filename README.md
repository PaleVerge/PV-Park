# 停车场管理系统 (Parking Management System)

一个基于 C 语言编写的控制台停车场管理系统，使用链表管理车辆信息，支持停车登记、缴费离场、信息查询和数据统计等功能。

---

## 功能特性

| 功能 | 说明 |
|------|------|
| 🅿️ 停车登记 | 选择车型后自动分配最近空车位，记录入场时间 |
| 💰 缴费离场 | 按停车时长自动计费，支持手动输入离场时间 |
| 🔍 信息查询 | 支持按车位号、车牌号查询车辆停放信息 |
| 📊 数据统计 | 查看各区域停车数量、超时车辆、月营业额等 |

---

## 区域与收费

| 区域 | 车型 | 车位数 | 单价（元/小时） |
|------|------|--------|----------------|
| A 区 | 轿车 | 20 | 3 |
| B 区 | 中型 / 货车 | 15 | 4 |
| C 区 | 大型 / 货车 | 10 | 5 |

- 不足 1 小时按 1 小时计费
- 停车超过 5 小时的车辆会被标记为超时车辆

## 编译运行

**环境要求：** Windows 系统（使用了 `windows.h` 中的控制台 API）

```bash
# 使用 GCC 编译
gcc Park_Manage_System.c -o Park_Manage_System.exe

# 运行
Park_Manage_System.exe
```

## 使用指南

1. **停车**：选择 `[1]我要停车` → 选择车型 → 输入当前时间 → 系统自动分配车位
2. **缴费**：选择 `[2]我要交费` → 输入车牌号 → 输入离场时间 → 查看费用明细
3. **查询**：选择 `[3]信息查询` → 选择查询方式（车位号 / 车牌号）
4. **统计**：选择 `[4]数据统计` → 查看区域停车数、超时车辆、月收费等
5. **退出**：选择 `[5]退出系统`，数据自动保存到 `.dat` 文件

## 数据结构

```c
typedef struct parker {
    int pos_id;          // 车位号
    char car_id[9];      // 车牌号
    struct time {
        int year, month, day, hour, minute;
    } park;              // 入场时间
    struct time leave;   // 离场时间
    int price;           // 区域单价
    int capacity;        // 区域总车位数
    char area;           // 区域（A/B/C）
    struct parker *next; // 下一个节点
} PARKER;
```

车辆信息以**单向链表**形式组织，每个区域（A/B/C）各维护一条链表。程序启动时从 `.dat` 文件加载数据，退出时自动保存。

---

## 技术细节

- 控制台使用 UTF-8 编码输出（`SetConsoleOutputCP(65001)`）
- 时间差计算使用标准库 `mktime` 和 `difftime`
- 数据持久化采用二进制文件读写（`fread` / `fwrite`）
- 空车位查找采用顺序遍历，优先分配最小编号
